# Story 1: <Searching>

## User Story & Acceptance Criteria
* **User Story:**As a casual gamer, I want to search for a game by its title so that I can quickly find and read its reviews.   
* **Acceptance Criteria:**
  Given a game titled "Cuphead" exists in the database, when I search for "Cuphead", then the system displays "Cuphead" in the search results with a link to its review page
